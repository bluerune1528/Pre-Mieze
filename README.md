# Commit messages

Format: `type: short description`

| Type | Use for |
|------|---------|
| `feat` | new feature or project step |
| `fix` | bug fix or improvement to existing behavior |
| `docs` | README or comments only |
| `refactor` | restructure code, same behavior |
| `test` | add or change tests |
| `chore` | setup, `.gitignore`, housekeeping |
